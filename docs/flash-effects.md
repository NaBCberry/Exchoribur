# 块内闪烁效果

在主时间轴的颜色块内右键，选择「慢速闪烁」「中速闪烁」或「快速闪烁」，
在鼠标所在时间创建一个默认一秒的效果框（到父块结尾不足一秒时自动缩短）。
三种模式对应已有设备协议的 1 Hz、2 Hz、4 Hz。

效果框左上角标注模式。拖动效果框内部可调整时间位置，左右边缘出现横向缩放光标时
拖动可拉长或缩短。效果始终限制在父块的通道和时间范围内，不会拖到其他通道。
拖动外层颜色块的标题栏或未被效果覆盖的区域，可整体移动颜色和效果。
双击外层块标题栏仍可打开颜色帧编辑器，即使效果框覆盖了整个块。
效果框上右键可切换模式或删除。每次操作都进入已有的撤销/重做历史。

## 调整外层颜色块边界

鼠标靠近颜色块左右边缘（约 5 像素）时出现横向缩放光标，按住左键拖动可调整起止时间。
效果框与父块边缘重合时，从父块标题栏的左右边缘调整颜色块，效果框边缘仍调整效果。
拖动块中间仍然是整体移动，缩放只调整当前块，不批量调整链接组内的其他块。

边缘调整采用裁剪/延长，不改变帧间距和播放速度：左边缘向右收时保留新起点处的颜色，
其余帧保持原来的绝对时间；向外扩展时延续首尾颜色。效果只保留与新边界相交的部分，
不会自动延长闪烁效果。块至少保留一个正长度和一帧。松开鼠标后产生一步撤销记录，
撤销可以完整恢复被裁掉的帧与效果。

打开工程会先异步读取参考视频的时长，再结束加载；无需先按播放，主时间轴和块编辑器
就覆盖视频末段。灯光块可以早于视频结束，也可以将右边缘延长到原块结尾之后。
边缘拖动采用不截断到可见范围的时间换算；播放头定位仍限制在可见范围内。

参考视频已知时，播放范围固定为 `[0, 视频时长]`，定位、逐帧、播放和循环都不进入范围外。
时间轴和块编辑器仍显示全部灯光内容，0 之前和视频结束之后共用半透明灰色蒙版。
没有参考视频或尚未取得时长时，沿用灯光内容的播放范围。

每次开始拖动时按原块分类：完整位于视频内（含边界）的块，左右边缘和平移都不能越界；
已有部分在灰色区域的块可自由移动、延长和缩短。手势中不会因暂时进入视频而改变规则，
松手后下一次拖动重新判断。块头接近 0、块尾接近视频结束点时，在约 8 像素内吸附。
多选或链接组一起平移时保持相对位置，组内原本在视频内的任意块都会限制整组的位移。

效果只覆盖闪烁模式，底下的颜色变化仍然生效。多个效果重叠时，集合中后面的效果优先；
新增或编辑效果会把它放到集合最后。效果起止采用左闭右开区间，结束时恢复常亮，
不清除颜色。旧工程和 CSV 中的连续闪烁帧自动合并成效果框；其他已有模式保持原样。

工程 JSON 在块内增加可选的 `Effects` 集合，包含 `Id`、相对父块的 `Offset`、
`Length`（毫秒）和 `Mode`。没有该字段时从原帧读取效果，显式空集合表示没有效果。
CSV 导出把效果起止时间加入状态变化点，并输出实际取样后的模式与颜色。
